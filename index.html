About

Bubblestrap is a fast, lightweight Roblox bootstrapper. It's an upgraded version of Fishstrap, featuring code rewrites to fix bad code and make it cleaner, faster, and easier on your system.

🫧 Features

Integrations

  • Activity tracking & detailed player logs
  • Detailed server information (Thanks to RoValra)
  • Fully customizable Discord Rich Presence
  • Multi-instance support
  • Prompt to confirm when launching another Roblox instance
  • Auto-launch integrations (launch other programs with Roblox)
  • Don't exit to the desktop app

Bootstrapper

  • Memory trimmer with threshold & interval
  • Disable Roblox crash handler to reduce resource usage
  • Background updates
  • Auto-update Bubblestrap
  • Cache, logs, and Bubblestrap log cleaner
  • Roblox System Tray options (Modal / Minimize to Tray)
  • Roblox App theme selector
  • Hide version and production details
  • Toggle launch Roblox on startup

Deployment

  • Channel changer
  • Skip Roblox updates
  • Force Roblox reinstallation
  • Install previous Roblox versions
  • Use static directory for Roblox

Mods

  • Use custom fonts
  • Use custom emojis
  • Custom death sounds
  • Old 2014 character sounds
  • Old avatar editor background (2020)
  • Custom Roblox & Roblox Studio icons
  • Customize cursors (ShiftLock, Arrow, IBeam, etc.)
  • Cursor sets with easy import & export

Other

  • FFlag settings & FFlag editor
  • Framerate cap unlocking
  • Custom Bubblestrap game invite links (DEEPLINK)
  • Roblox Studio support
  • Global Settings page
  • Full translations unlike other bootstrappers
  • No analytics at all
